# 2º Año — DAM

### Desarrollo de Aplicaciones Multiplataforma

---

## Descripción

Repositorio que recopila el contenido del **segundo año del Grado Superior en Desarrollo de Aplicaciones Multiplataforma**, organizado por asignaturas.

> Los proyectos de **Programación Multimedia y Dispositivos Móviles** están en un repositorio aparte: [Programacion-Multimedia-y-Dispositivos-Moviles](https://github.com/acusanty16-svg/Programacion-Multimedia-y-Dispositivos-Moviles), porque las rutas con caracteres no ASCII (`ñ`, tildes) rompen la compilación de Android en Windows.

## Asignaturas

### 01 — Acceso a Datos
Manejo de ficheros, tratamiento de XML con JAXB y acceso a bases de datos mediante JDBC.

### 02 — Desarrollo de Interfaces
Diseño y desarrollo de interfaces gráficas y aplicaciones de escritorio en Java.

### 03 — Digitalización Aplicada al Sector Productivo
Contenido del módulo de digitalización aplicada al tejido productivo.

### 04 — Inglés
Inglés técnico orientado al ámbito profesional y a la documentación técnica.

### 05 — MPO
Contenido del módulo profesional optativo.

### 06 — Programación de Servicios y Procesos
Creación y gestión de procesos, hilos y comunicación entre ellos en Java.

### 07 — Sistema de Gestión Empresarial
Instalación, configuración y uso de Odoo como ERP, incluyendo despliegue con Ubuntu Server y Docker.

### 08 — Sostenibilidad Aplicada al Sistema Productivo
Contenido del módulo de sostenibilidad aplicada al sistema productivo.
